# Analytics input contract

The `survey-analytics` skill consumes:

1. one survey schema
2. one answers dataset

## Supported schema input

- the repaired schema generated by `survey-creator`
- a schema-equivalent survey JSON that follows the same field contract

## Supported answers input

- JSON array of submission documents
- JSONL file with one submission document per line

## Minimum answer document

```json
{
  "surveyId": "survey-310992845731864576",
  "submittedAt": 1748320800000,
  "answers": [],
  "extra": {}
}
```

## Analysis boundary

`survey-analytics` is responsible for:

- summarization
- segmentation
- distribution analysis
- recommendations

It is not responsible for:

- collecting responses
- validating login permissions
- hosting dashboards
- storing data
